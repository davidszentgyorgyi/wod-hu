# Tapasztalat

A **Tapasztalati Pontok** (Experience Points, röviden XP) azt mérik, mennyit fejlődött egy
karakter a játék során. A Mesélő (Storyteller) jellemzően minden játékalkalom (session) végén ad
XP-t a játékosoknak, amit Attribútumok, Képességek, Diszciplínák vagy más tulajdonságok
fejlesztésére költhetnek.

A fejlesztés költsége jellemzően a fejlesztendő tulajdonság jelenlegi szintjétől függ — minél
magasabb szinten áll valami, annál több XP-be kerül egy további szint.

!!! warning "Terminológia megjegyzés"
