# Képességek

A **Képességek** (Skills) a karakter tanult tudását és gyakorlati jártasságát jelölik — egy
[Attribútummal](attributumok.md) kombinálva adják a [dobáskészletet](dobasrendszer.md). Három
kategóriába sorolhatók, mindegyikben kilenc Képesség található.

## Fizikai Képességek

| Képesség | Angol eredeti |
|---|---|
| Atlétika | Athletics |
| Verekedés | Brawl |
| Kézművesség | Craft |
| Vezetés (jármű) | Drive |
| Lőfegyverek | Firearms |
| Tolvajmesterség | Larceny |
| Közelharc | Melee |
| Lopakodás | Stealth |
| Túlélés | Survival |
