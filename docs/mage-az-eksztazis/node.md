# Node

A **Node** egy hely, ahol a **[Quintessence](quintessence.md)** (tiszta mágikus energia)
természetesen felhalmozódik — ilyen lehet egy ősi szent hely, egy erős érzelmi esemény
helyszíne, vagy egy véletlen kozmikus "repedés" a valóságban.

## Jelentősége

A Node-ok birtoklása stratégiai fontosságú a **[Mágusrendek](magusrendek.md)** és a
**[Technokrácia](technokracia.md)** között — minél több Node felett uralkodik egy csoport,
annál nagyobb mágikus erőforráshoz fér hozzá.
