# Mágusrendek (Tradíciók)

A Mage: The Ascension világában a mágusok kilenc **Tradícióba** (Traditions) szerveződnek,
mindegyik a valóság megváltoztatásának más filozófiai megközelítését képviseli.

| Tradíció | Jellemzés |
|---|---|
| Akashic Brotherhood | Harcművészetre és meditációra épülő, ázsiai eredetű rend |
| Celestial Chorus | Monoteista, isteni erő általi mágiát gyakorló rend |
| Cult of Ecstasy | Transz és extázis általi megvilágosodást kereső rend |
| Dreamspeakers | Törzsi, sámánisztikus hagyományokat követő rend |
| Euthanatos | Halál és körforgás-filozófiára épülő rend |
| Order of Hermes | Nyugati, ceremoniális-rituális mágiát gyakorló rend |
| Sons of Ether | "Tudományos mágiát" (etherikus tudomány) gyakorló rend |
| Verbena | Természet- és földközpontú, pogány hagyományú rend |
| Virtual Adepts | Digitális/technológiai valóságot hackelő, modern rend |

## Közös gyökér, szétváló utak

A kilenc Tradíció eredetileg nem alkotott egységes szervezetet — évszázadokon át külön-külön
gyakorolták saját mágiájukat, néha egymással is szembenállva. Csak a tudományos
világszemlélet (és a Technokrácia) növekvő fenyegetése kényszerítette őket arra, hogy
szövetségbe tömörüljenek, és közösen próbálják fenntartani a varázslatos valóságszemlélet
létjogosultságát a modern világban. Ez a szövetség ma is feszült: a Tradíciók gyakran jobban
vitatkoznak egymás paradigmáján, mint amennyire együtt harcolnak a közös ellenféllel.

## Ellenfelük

A Tradíciók fő ellenfele a **[Technokrácia](technokracia.md)**, amely a tudományos, konszenzus-
alapú valóságszemléletet próbálja egyedüli igazságként rákényszeríteni a világra.
