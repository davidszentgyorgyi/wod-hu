# Quintessence

A **Quintessence** a valóság mögötti tiszta mágikus energia — a mágusok ezt használják fel a
[Szférákkal](szferak.md) végzett hatásaik erősítésére. Bizonyos helyeken (**Node**-okon)
természetesen felhalmozódik, és összegyűjthető, tárolható (pl. **Tass** formájában).
