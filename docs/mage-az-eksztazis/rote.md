# Rote

A **Rote** egy előre kidolgozott, gyakran rituális mágikus eljárás, amelyet egy mágus
megismételhetően, nagyobb megbízhatósággal tud végrehajtani, mint egy teljesen improvizált
[Szféra](szferak.md)-hatást. A Rote-ok gyakran generációkon át öröklődnek egy
[Mágusrenden](magusrendek.md) belül, saját hagyományos szimbolikájukkal és rituális elemeikkel.
