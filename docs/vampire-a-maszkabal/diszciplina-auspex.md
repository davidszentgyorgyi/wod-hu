# Auspex

Az **Auspex** Diszciplína érzékfeletti észlelést és mentális képességeket ad. Fő klánjai:
Toreador, Malkavian, Tremere, Salubri.

| Szint | Erő | Hatása |
|---|---|---|
| 1 | Heightened Senses | Az Auspex értékét hozzáadja az érzékelési próbákhoz |
| 1 | Sense the Unseen | Észleli a természetfeletti módon láthatatlan dolgokat (pl. Rejtőzést használókat) |
| 2 | Premonition | Látomásokat és előjeleket kap a közelgő eseményekről |
| 2 | Share the Senses | Megoszthatja érzékeit egy másik Vértestvérrel vagy halandóval |
| 3 | Scry the Soul | Aurákat tud olvasni |
| 3 | The Eyes of Beasts | Megosztja érzékeit egy általa irányított állattal |
| 4 | Clairvoyance | Egy egész városrészről egyszerre gyűjt információt |
| 4 | Telepathy | Gondolatait kivetíti, vagy felszíni gondolatokat/érzelmeket olvas |
| 5 | Possession | Átveheti egy halandó testének irányítását |
