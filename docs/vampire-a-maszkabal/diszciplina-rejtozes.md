# Rejtőzés

A **Rejtőzés** (Obfuscate) Diszciplína láthatatlanná válást és megtévesztést ad. Fő klánjai:
Nosferatu, Malkavian, Ravnos, Banu Haqim.

| Szint | Erő | Hatása |
|---|---|---|
| 1 | Cloak of Shadows | Mozdulatlanul állva láthatatlanná válik |
| 1 | Ensconce | Kisebb tárgyakat rejt el magán |
| 2 | Unseen Passage | Mozoghat, miközben láthatatlan marad |
| 2 | Chimerstry | Rövid, de élénk egyérzékszervi hallucinációt kelt |
| 3 | Mask of a Thousand Faces | Egy generikus, környezetbe illő személy hangját és kinézetét veszi fel |
| 3 | Fata Morgana | Kidolgozott, többérzékszervi hallucinációkat kelt |
| 4 | Conceal | Egy kisebb épületig bezárólag bármit láthatatlanná tehet |
| 5 | Cloak the Gathering | Kiterjeszti a Rejtőzést a társaira is |
| 5 | Imposter's Guise | Egy konkrét személynek álcázza magát |
