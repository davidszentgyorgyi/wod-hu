# Uralás

Az **Uralás** (Dominate) Diszciplína mások elméjének irányítását adja. Fő klánjai: Ventrue,
Malkavian, Tremere, Lasombra, Tzimisce.

| Szint | Erő | Hatása |
|---|---|---|
| 1 | Cloud Memory | Elfelejteti a célponttal az elmúlt pár percet |
| 1 | Compel | Rövid parancsot ad ki a célpontnak |
| 2 | Mesmerize | Hosszabb, bonyolultabb parancsot ad ki |
| 2 | Dementation | Pszichotikus rohamot vagy idegösszeomlást vált ki |
| 3 | The Forgetful Mind | Átírja a célpont korábbi emlékeit |
| 3 | The Stolen Voice | Elveszi egy áldozat beszédképességét |
| 4 | Ancestral Dominion | Parancsokat adhat ki a leszármazottainak szemkontaktus nélkül |
| 4 | Tabula Rasa | Teljesen kitörli a célpont emlékezetét |
| 5 | Mass Manipulation | Egyszerre több célpontra is kiterjeszti más Uralás-erőit |
| 5 | Terminal Decree | Halálos vagy sérülést okozó parancsokat adhat ki |
