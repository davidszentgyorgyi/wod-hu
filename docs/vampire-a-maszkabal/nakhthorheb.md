# Nakhthorheb

**Nakhthorheb**, ismertebb nevén az "Első Fiú", a **[Ministry](ministry.md)** klán
**Hierofántáinak** vezetője volt a Sötét Középkorban — azok közül a legősibb vének közül
egy, akik Set isten eltűnése után magukra vállalták a klán irányítását.

## Set közvetlen Gyermeke

A legenda szerint Nakhthorheb Set saját nomád törzsébe született, és az elsők között kapta meg
az Ölelést magától az Antedeluviánustól. Miután Set nyomtalanul eltűnt, hét Hierofánta állt
össze, hogy a klán felügyelőjévé nyilvánítsák magukat — közülük Nakhthorheb vált a
legbefolyásosabbá, aki végső soron minden döntés forrása, bár formálisan minden Hierofántának
jóvá kell hagynia azokat.

## Egyiptom dicsőségének álma

Nakhthorheb Tanisz pusztulása óta Alsó-Egyiptom pusztaságait járja, Set egykori útját követve,
és Egyiptom régi dicsőségének visszaállítását tervezi. Idegenekkel szemben bizalmatlan, és
sosem volt hajlandó nem egyiptomi halandót a klánba Ölelni — a szabályok és előírások
megalkotását megalázó, de szükséges rossznak tartja, amit Set szándékainak ismerete miatt
kényszerűségből vállal.

## Torporban

A modern éjszakákra Nakhthorheb Torporba merült — a szóbeszéd szerint a Set egyik Alapító
Templomában, egy Uganda-i, Victoria-tó melletti rejtekhelyen nyugszik, és a mai napig nem
ébredt fel.
