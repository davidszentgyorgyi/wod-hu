# Kemintiri

**Kemintiri** egy ősi, Set egykori Gyermeke a **[Ministry](ministry.md)** klánból — a
vámpírtársadalom legkeresettebb szökevénye, aki a **Vörös Lista** létrejötte óta annak első
helyén áll. A Lista eredetileg kifejezetten az ő elfogására született.

## Papnő, aki elárulta Teremtőjét

Kemintiri az ókori Egyiptomban élt papnőként, Set templomának egyik legbefolyásosabb
szolgálójaként — egészen addig, amíg Set megbízásából be nem épült az Ízisz-kultuszba, hogy
ellopja tőlük a legendás Élet Varázsigéjének titkát. Évtizedes tanulmányozás után végül
megszerezte a tudást, de ezalatt meggyőződéses hívévé vált Ízisz fiának, Hórusznak — és
elárulta Setet, megtartva magának a Varázsige titkát.

## A szabadulás és a megjelölés

Set elfogta és súlyosan megbüntette árulásáért, majd — annak tudatában, hogy ezzel örökre
megakadályozza, hogy Kemintiri valaha is múmiává válhasson — a Vér Átkával jelölte meg,
vámpírrá téve őt. Amit Set nem tudott: az a mágia, amely Kemintirit immunissá tette az
Uralás Diszciplínájával szemben, a Vérkötelék ellen is megvédte — így Set soha nem tudta
kikényszeríteni belőle a Varázsige titkát, Kemintiri pedig végül saját tudása
felhasználásával szabadult ki fogságából.

## Évezredek bujkálásban

Kemintiri ezután évszázadokon át bolyongott, időnként elvesztve emberségét, majd ismét
visszanyerve azt — egy időben Mithras Methuselah szeretője is volt, de kapcsolatuk árulással
és leleplezéssel ért véget. Set máig üldözi, hiszen Kemintiri az egyetlen fennmaradt forrás,
aki ismeri a régóta keresett Varázsige titkát — a Kamarilla pedig azért hajtja, mert tartanak
tőle, hogy saját múmia-seregét akarja létrehozni a tudás felhasználásával.
