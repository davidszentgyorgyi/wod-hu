# Klánok

A World of Darkness vámpírjai tizenhárom fő **Klánba** sorolhatók, mindegyiknek saját jellemző
Diszciplínáival, kultúrájával és hátrányával.

| Klán | Fő Diszciplínák | Jellemző szekta |
|---|---|---|
| [Brujah](brujah.md) | Celerity, Potence, Presence | Anarch (korábban Kamarilla) |
| [Ventrue](ventrue.md) | Dominate, Fortitude, Presence | Kamarilla |
| [Toreador](toreador.md) | Auspex, Celerity, Presence | Kamarilla |
| [Nosferatu](nosferatu.md) | Animalism, Obfuscate, Potence | Kamarilla |
| [Malkavian](malkavian.md) | Auspex, Dominate, Obfuscate | Kamarilla |
| [Gangrel](gangrel.md) | Animalism, Fortitude, Protean | Független / Anarch |
| [Tremere](tremere.md) | Auspex, Dominate, Blood Sorcery | Kamarilla |
| [Lasombra](lasombra.md) | Dominate, Oblivion, Potence | Szabbat (részben Kamarilla) |
| [Tzimisce](tzimisce.md) | Animalism, Dominate, Protean | Szabbat |
| [Banu Haqim](banu-haqim.md) | Blood Sorcery, Celerity, Obfuscate | Kamarilla (részben független) |
| [Ravnos](ravnos.md) | Animalism, Fortitude, Obfuscate | Független |
| [Salubri](salubri.md) | Fortitude, Auspex, gyógyító ág | Független (ritka) |

!!! note "Hol a 13. klán?"
    A hagyomány 13 fő klánt említ, de a tagság és a szekta-hovatartozás kiadásonként (Classic WoD
    vs. V5) változott — pl. a Ravnos és a Salubri az 5. kiadásban nem alapklán, hanem majdnem
    kihalt, ritka vérvonal. Lásd az egyes klán-cikkeket a részletekért.
