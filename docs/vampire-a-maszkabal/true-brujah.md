# True Brujah

A **True Brujah** egy ritka [Bloodline](bloodline-ok.md) — a [Brujah](brujah.md)
Antedeluviánus eredeti leszármazottai, akik nem Troile diablerizáló vonalából származnak,
hanem közvetlenül az eredeti, higgadt, logikus Antedeluviánustól.

## Jellemzőik

A True Brujah hidegebb, racionálisabb, kevésbé szenvedélyes, mint a főklán — gyakran az idő
manipulálásához köthető Diszciplínákkal rendelkeznek, ahelyett, hogy a Brujah megszokott
Sebesség/Hatóerő/Jelenlét (Celerity/Potence/Presence) kombinációját használnák.
