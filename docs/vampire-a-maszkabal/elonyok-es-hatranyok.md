# Előnyök és Hátrányok

Az **Előnyök** (Merits) és **Hátrányok** (Flaws) olyan 1-5 pontos karakter-tulajdonságok, amelyek
a [Klán](klanok.md) és a [Ragadozó-típus](predator-tipus.md) által adott alapokon felül finomítják
a karaktert. Az Előnyök szinte mindig vehetők pontért karakteralkotáskor; sok Hátrány extra
pontot ad, amit más Előnyökre lehet elkölteni.

Az Előnyök/Hátrányok egy része **belső** (a karakter személyét, testét, pszichéjét jellemzi),
más része **Háttér** (Background) jellegű — azaz külső kapcsolatokat, vagyont, befolyást ír le.

!!! warning "Terminológia megjegyzés"
    A "Merit" → "Előny", "Flaw" → "Hátrány" és "Background" → "Háttér" fordítás munkafordítás,
    az általános magyar szerepjátékos szóhasználatra épül, nincs WoD-specifikus forrással
    megerősítve. Lásd [TERMINOLOGY.md](https://github.com/davidszentgyorgyi/wod-hu/blob/main/TERMINOLOGY.md).

## Belső Előnyök/Hátrányok — főbb kategóriák

| Kategória | Jellemző példák |
|---|---|
| **Archaikus** | Hátrány: elavult meggyőződések, nem tud modern technológiát használni (csak idősebb Vértestvéreknél) |
| **Vérkötelék-érzékenység** | Hátrány: azonnal megköteleződik első ivásra; Előny: ellenállóbb a Vérköteléknek, vagy gyorsabban bomlik nála |
| **Vérszerzés** | Hátrány: csak állatból/halottból élhet, vagy kizár egy prédatípust; Előny: Iron Gullet (hűtött/romlott vért is megiszik) |
| **Kinézet** | Hátrány: Visszataszító vagy Csúnya; Előny: Gyönyörű vagy Elbűvölő |
| **Mitikus** | Hátrány: Karóbaverés végzetes rá, vagy egy folklorisztikus gyengesége van (pl. ezüst, szenteltvíz); Előny: képes evésre (nem táplálkozásra) |
| **Pszichológiai** | Hátrány: akaratgyenge, vagy kényszeresen új tapasztalatokat keres |
| **Szerhasználat** | Hátrány: függőség egy nem-vér szertől (alkohol, drog) |
| **Ghoul-specifikus** | Hátrány: elszenvedi ura Átkát; Előny: szorosabb empatikus kötődés az urával |

## Háttér-jellegű Előnyök/Hátrányok

A Hátterek külső kapcsolatokat, vagyont és befolyást írnak le — ezek adják a karakter
"hálóját" a Krónikában:

| Háttér | Mit ad | Jellemző Hátrány-párja |
|---|---|---|
| **Szövetségesek** (Allies) | Hűséges halandó(k), akik segítenek | Ellenség (Enemy) |
| **Kapcsolatok** (Contacts) | Információ-, szolgáltatás- vagy áruforrás | — |
| **Hírnév** (Fame) | Mennyire ismert a karakter | Hírhedtség, Sötét titok |
| **Befolyás** (Influence) | Súly a halandó közösségben | Megvetett, Nem szeretett |
| **Fészek** (Haven) | Biztonságos alvóhely, extrákkal (könyvtár, labor, őrség, titkos kijárat) | Kompromittált, Ijesztő, Kísértetjárt |
| **Nyáj** (Herd) | Rendszeresen elérhető, panaszmentes vérforrás | Nyilvánvaló ragadozó |
| **Álarc** (Mask) | Hamis identitás erőssége | Ismert üresfejű / Ismert holttest |
| **Mawla** | Vértestvér-szövetséges, aki segít, tanácsot ad | Ellenlábas (Adversary) |

## Hogyan illeszkedik a karakteralkotásba

A V5 karakteralkotás jellemzően így kezeli az Előnyöket/Hátrányokat:

1. A [Ragadozó-típus](predator-tipus.md) már ad néhányat automatikusan (pl. Iron Gullet, Nyáj).
2. A játékos ezután szabad pontokat költhet el további Előnyökre — ezt a Mesélő/krónika
   határozza meg (jellemzően 7 pont körül az alapkönyv szerint).
3. Hátrányok felvétele extra pontot ad, amit más Előnyökre lehet fordítani — de csak annyi
   Hátrány vehető fel, amennyi a koncepcióba valóban beleillik, nem "pontfarmolásra".
