# Állatiasság

Az **Állatiasság** (Animalism) Diszciplína az állatvilág és a vámpírok belső Bestiája feletti
hatalmat adja. Fő klánjai: Nosferatu, Gangrel, Tzimisce.

| Szint | Erő | Hatása |
|---|---|---|
| 1 | Bound Famulus | Köteléket hoz létre egy állattal, ami megkönnyíti a további Állatiasság-erők használatát |
| 1 | Sense the Beast | Megérzi a Bestiát más vámpírokban, halandókban és természetfeletti lényekben |
| 2 | Feral Whispers | Hívhat és kommunikálhat egy állattal |
| 2 | Atavism | Egy állatot ideiglenesen ösztönös, agresszív állapotba taszít |
| 3 | Animal Succulence | Állatok vérével is tud táplálkozni, extra Éhséget csillapítva |
| 3 | Quell the Beast | Megnyugtat halandókat, vagy kihoz egy vámpírt az Őrjöngésből |
| 4 | Subsume the Spirit | Mentálisan átveszi egy állat irányítását |
| 5 | Animal Dominion | Tökéletesen irányít állatcsordákat és -rajokat |
| 5 | Drawing Out the Beast | Azonnali Őrjöngésbe kényszerít egy célpontot |
