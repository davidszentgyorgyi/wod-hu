# Jelenlét

A **Jelenlét** (Presence) Diszciplína érzelmek és figyelem feletti hatalmat ad. Fő klánjai:
Brujah, Ventrue, Toreador.

| Szint | Erő | Hatása |
|---|---|---|
| 1 | Awe | Hozzáadja Jelenlét-értékét a Rábeszélés és Előadás próbáihoz |
| 1 | Daunt | Hozzáadja Jelenlét-értékét a Megfélemlítés próbáihoz |
| 2 | Lingering Kiss | Bónuszt kap a Szociális próbáihoz azok ellen, akiket megharapott |
| 3 | Dread Gaze | Rettegést kelt a célpontban |
| 3 | Entrancement | Kisebb kéréseket tehet a célpontnak, Szociális bónusszal |
| 4 | Irresistible Voice | Hangjával is tud Uralás-erőket használni |
| 4 | Summon | Magához hívhat bárkit, akit korábban elbűvölt vagy megharapott |
| 5 | Majesty | Jelenlétében senki sem tud ellene cselekedni egy konfliktusban |
| 5 | Star Magnetism | Az Awe, Daunt, Entrancement élő közvetítésen/elektronikus úton is működik |
