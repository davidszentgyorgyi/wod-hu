# Set

**Set**, más néven **Sutekh**, a **[Ministry](ministry.md)** klán (korábban Set Követői)
alapító **Antedeluviánusa** — legendája annyi ellentmondó mítoszból áll össze, hogy
valódi története a mai napig tisztázatlan.

## Az elűzött herceg

A legenda szerint Set az ókori Egyiptomban élt, a Nílus mentén, közel hétezer évvel ezelőtt —
hatalmas vadász és harcos volt, akinek egyetlen vetélytársa saját bátyja, Ozirisz volt. Szülei
halála után Setet száműzték, míg Ozirisz hűséget fogadott nagyapjuknak, és annak halála után
átvette a trónt. Amikor Set megpróbált kibékülni bátyjával, az megtagadta tőle a
visszatérést — ekkor vette fel a "Sutekh" nevet, és új, saját útját kezdte járni.

## Az Ölelés és az istenné válás

A legenda szerint Set vándorlása közben találkozott Teremtőjével, és Ölelésben részesült —
ezután kígyók és csúszómászók iránti szenvedélye, valamint az a hite, hogy valódi istenséggé
vált, meghatározta egész unélete hátralévő részét. Visszatért Egyiptomba, és legyőzte
Ozirisz királyt — ezzel egy évezredeken át tartó konfliktust indított el Ozirisz fiának,
Hórusznak múmia-kultuszával.

## Eltűnés a modern éjszakák előtt

Set alapította meg a **Kígyó Klánt**, amelyből a mai Ministry (korábban Set Követői)
klán ered, és tanította meg híveinek a **[Serpentis](serpentis.md)** Diszciplínát.
Kr. e. 33-ban történt felébredése után nyomtalanul eltűnt — a legenda szerint valahol
Egyiptom sivatagi homokja alatt, Torporban nyugszik a mai napig.
