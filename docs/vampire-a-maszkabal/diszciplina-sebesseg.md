# Sebesség

A **Sebesség** (Celerity) Diszciplína emberfeletti gyorsaságot ad. Fő klánjai: Brujah,
Toreador, Banu Haqim.

| Szint | Erő | Hatása |
|---|---|---|
| 1 | Cat's Grace | Automatikusan sikerül az egyensúly megtartása |
| 1 | Rapid Reflexes | Fedezék nélkül is kitér lövések elől, büntetés nélkül |
| 2 | Fleetness | Hozzáadja Sebesség-értékét a nem-harci Ügyesség-próbákhoz |
| 3 | A Thousand Cuts | Számtalan sekély, vérző sebet okoz a célponton |
| 3 | Blink | Nagy távolságokat tesz meg, és közben még cselekedhet (pl. támadhat) |
| 4 | Unerring Aim | Megakadályozza, hogy a célpont kitérjen a támadása elől |
| 5 | Lightning Strike | Megakadályozza, hogy a célpont kitérjen közelharci támadása elől |
| 5 | Split Second | Felülírja a Mesélő elbeszélését, hogy egy pillanat alatt cselekedjen |
