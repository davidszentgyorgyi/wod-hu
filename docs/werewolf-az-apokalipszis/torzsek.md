# Törzsek

A [Garou](garou.md) társadalom 13 **Törzsre** (Tribe) oszlik, mindegyiknek saját kultúrájával,
filozófiájával és kapcsolatával Gaiához.

| Törzs | Jellemzés |
|---|---|
| Black Furies | Harcos nők törzse, az Anyaistennőt tisztelik |
| Bone Gnawers | Városi szegények, hajléktalanok közt élő, alulértékelt törzs |
| Children of Gaia | Békepárti, gyógyító szemléletű törzs |
| Fianna | Kelta eredetű, bárdok és harcosok törzse |
| Get of Fenris | Skandináv eredetű, harcias, kérlelhetetlen törzs |
| Glass Walkers | Modern, technológia-barát, városi törzs |
| Red Talons | Kizárólag farkas alakban élő, emberfajt gyűlölő törzs |
| Shadow Lords | Machiavellista, hatalomra törő törzs |
| Silent Striders | Vándorló, Egyiptomi eredetű, szellemvilággal szoros kapcsolatú törzs |
| Silver Fangs | Hagyományosan vezető, arisztokratikus törzs, de hanyatlásban |
| Stargazers | Ázsiai, meditatív, harcművészetekre épülő törzs (később elhagyta a Garou Nemzetet) |
| Uktena | Amerikai őslakos eredetű, titkokat és rejtélyeket kutató törzs |
| Wendigo | Amerikai őslakos eredetű, az európai gyarmatosítókat gyűlölő törzs |
