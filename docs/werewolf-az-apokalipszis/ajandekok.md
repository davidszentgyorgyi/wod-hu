# Ajándékok

Az **Ajándékok** (Gifts) a [Garou](garou.md) természetfeletti képességei — ezeket nem
veleszületett erőként, hanem **szellemektől tanult** tudásként kapják. Egy Garou karakter
jellemzően egy szellem-tanítótól (gyakran egy totemikus szellemtől) sajátítja el az Ajándékot egy
rituálé keretében.

## Kapcsolat a törzsekkel és auspice-okkal

Egyes Ajándékok minden Garou számára elérhetők, mások kizárólag egy adott [Törzshöz](torzsek.md)
vagy egy adott **Auspice**-hoz (a Garou holdfázis szerinti "hivatásához", pl. Ahroun =
harcos) kötöttek.
