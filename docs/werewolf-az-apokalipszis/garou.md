# Garou

A **Garou** a vérfarkasok önmegnevezése a Werewolf: The Apocalypse univerzumban — Gaia (a Föld
szellemi anyja) harcosai, akik ember, farkas és köztes (Crinos) alakot is fel tudnak venni.
Küldetésük Gaia védelme a **[Wyrm](wyrm.md)** pusztító erejétől.

## Alakváltás (Shapeshifting)

A Garou öt alakot vehet fel: Homid (emberi), Glabro (félig átváltozott, emberszerű), Crinos (a
harci, farkasember alak), Hispo (nagy farkas) és Lupus (sima farkas). Harc közben jellemzően a
Crinos alakot használják.
