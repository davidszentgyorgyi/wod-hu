# Auspice-ok

Az **Auspice** egy [Garou](garou.md) társadalmi szerepét és hivatását jelöli, amelyet a holdfázis
határoz meg, amely alatt született. Öt Auspice létezik:

| Auspice | Holdfázis | Szerep |
|---|---|---|
| Ragabash | Újhold | Trükkster, kémkedő, szabályszegő |
| Theurge | Növő hold | Szellemi közvetítő, az Umbra szakértője |
| Philodox | Félhold | Bíró, igazságszolgáltató, közvetítő |
| Galliard | Csökkenő hold | Történetmondó, a Litania őrzője |
| Ahroun | Telihold | Harcos, a Garou első védelmi vonala |
