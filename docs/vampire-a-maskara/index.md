# Vampire: A Maskara

A **Vampire: The Masquerade** (magyarul: *Vámpír: A Maskara*) a World of Darkness legismertebb
szettingje, amelyben a játékosok vámpírokat (Kindred-eket) irányítanak egy modern városi
környezetben, a **Maskara** szabálya alatt — azaz titokban kell tartaniuk létezésüket az emberiség
elől.
